## 核心一句话

> **村庄是活的，而住在里面的村民不知道自己活在一个真的世界里。**

别的游戏没有这一层。所有设计取舍都拿这一句去问：

- 他在这儿干什么？—— **他以为他在打游戏**
- 他为什么留下？—— **因为村庄真的在长，不是因为他领到了任务**
- 他什么时候走？—— **他发现这是真的那天，或者村庄不值得他待那天**

---

## 设定（开发者原话整理）

**你（玩家）穿越到了异世界大陆。** 初始只有几间普通草屋。激活了一个系统，
系统能**从地球召唤玩家**过来，把这块大陆当成一个游戏世界。

- 玩家以为这只是一款游戏。他们会找 GM、会看攻略、会互相安利。
- 系统开局只能召几个人。他们帮你盖房子、做任务、收材料、杀野兽、攻副本。
- 你通过发任务拿资源，升级村庄，给村庄配**功能性建筑**——
  武器店、服装店让玩家买东西；试炼塔让玩家快速升级；防护罩挡住外面的攻击。
- 你作为村长，有时候**自己也会带人去攻副本**。
- 每个玩家有偏好：有人爱打副本，有人休闲，有人打 PvP。**这些用性格表现。**
- 玩家会在村内、防护罩内**自己摆摊**，你收摆摊费。
- 这个异世界大陆还有**本土角色、本土剧情**——这是不依赖玩家的第二条内容线。

### 本土角色的意义（重要，容易忘）

**如果只有玩家，玩家不上线时你的村庄是死的。** 有本土人，
村庄永远有事发生，而且是村长自己的故事，不是任务的副产品。

---

## 两条成长线（互不抢资源）

| | 长什么 | 怎么长 |
|---|---|---|
| **村庄** | 三间土屋 → 烟囱 → 井 → 围栏 → 铁匠铺 | 花钱盖，盖得**看得见** |
| **村长** | 不是拳头变大，是**视野变大** | 解锁新地图、新任务类型、防护罩罩得更远、开启传送 |

**两条线不能互相替代，也不能互相削弱。** 村庄盖得再好，村长不解锁就看不到外面。

---

## 性格：改的是效率，不是许可

> **开发者原话：「性格不是二极管。不是说这个玩家喜欢打副本，他就不会休闲了、
> 不会采集了，只是说效率会慢点。」**

**没有「只有他能做的活」。** 缺人时任何人都能顶，只是慢。
不要写「莽不采集」「傲不盖房子」这种硬门槛——那会把队伍凑法锁死。

性格改的是两件事：

| 性格 | 他要什么 | 做事的效率 | 他自己挑活儿时 | 村长为他准备什么 |
|---|---|---|---|---|
| **莽** | 强度 | 战斗最高，细活也干得了，只是嫌慢 | 主动挑战斗活 | 高难副本、好装备 |
| **傲** | 胜负 | 战斗高，脏活细活低（×0.6） | 挑**有对手的、难的** | 防护罩、仲裁、PK 规则 |
| **贪** | 财富 | 采集跑腿最高，战斗低 | 挑来钱多的 | 摊位区、抽成、税率 |

**傲拒绝的只是「粗活」**，不是所有活——有对手的活他抢着去。
撂了挑子也不等于不能干：他真去干了，速度依然只有 0.6 倍。

### 性格是两根轴，不是一根

```
轴一 · 他要什么              轴二 · 他投入多少
  莽  强度                    肝    每天上线
  傲  胜负                    随手  想起来玩
  贪  财富                    挂机  上线就站那
```

九宫格。**同样是莽，一个是肝帝，一个是指一天游——村长对这两种人的用法完全不同。**

## 作息：时区，不是早班晚班

> **开发者原话：「什么早班晚班的，不区分的，地球一边是晚上，另一边就是早上了呀。」**

他们是**从地球各处来的人**。所以他们的作息表上写的是**自己那边**的时间，
换算到村庄时钟要减去 UTC 偏移。**不要分早班晚班——村庄不会天黑，因为地球上
永远有一边是白天。**

这是「村庄随人口慢慢亮起来」的全部机制，而且它是免费的：人本来就来自各个时区，
你只要别把他们按同一个钟点排。

**实测覆盖曲线**（`--selftest` 会打印，· = 没人）。**这是当前实现的测量结果，不是设计承诺：**

```
  人口  空档   0点————————————————————————————23点   峰值
    3   11    1111··111111·········222     2
    6    3    1111··1111221·1112211322     3
   10    0    122211122234212334421322     4
   20    0    335556655455334568754644     8
   40    0    99878+++++++76457+978+++    14
```

> **踩过的坑：把这个洞当 bug 找了半天。** 最早的作息表按玩家的钟点排，
> 结果「清晨 6-10 点」三种性格一个都不会上线——招一百人那个洞还在，
> 因为它是表里写死的。时区一散，洞自己就没了。
> **以后再看到「某个时段没人」，先查时区。**

## Core loop

1. **在酒馆召唤** — 来自不同世界的人，**每一个都不一样**
2. **看村庄自己过日子** — 时间照走，人按作息上线下线，每天村里自己发生几件事
3. **排班与配队** — 谁搭伙去做哪件事
4. **他们按性格行动** — 接不接、成不成、私不私吞，全看性格
5. **村庄长大** — 他们真的在建房子，你看得见
6. **发任务、收材料** — 村庄升级，村长解锁

**你不按键，村庄也在变。这是 M0 的验收标准，也是整个设计的地基。**

## 没有硬失败

卡住 = 材料不够，或者能撑这件事的人**正好不在 / 正在闹别扭 / 正在生病**。

---

## 村庄日常的一条硬规矩

> **事件必须改状态，不能只是写一句话。**

病倒的人真的干不了活，吵过架的人真的进不了同一支队。
如果一个事件写进杂谈却什么都不影响，那它就是装饰，**删掉**。

已经有真实后果的：病倒（停工）、打架（两人缺席一天 + 结仇）、
磨洋工（干活率 ×0.4）、想走（不肯出工）、结仇（同队 ×0.5）。
只有气氛没有后果的：闲逛 / 搭手 / 陌生人——留给后面的模块变成决策点。

## 模块顺序（每一块单独都能玩）

| | 模块 | 做完你能玩到什么 | 为什么是这个顺序 |
|---|---|---|---|
| **M0** ✅ | 村庄自己过日子 | **什么都不按**，村庄也在变 | 地基。不做这个，后面全是菜单 |
| **M1** | 性格是规则 | 两个村庄跑三天长出不同结果 | 「不靠你操作」的第一步 |
| **M2** | 副本是真实的地方 | 派弱队去危险副本，回来少了人 | 把按钮换成世界 |
| **M3** | 建筑是网，不是等级条 | 盖了试炼塔之后盖房真的变慢 | 经济开始互相咬合 |
| **M4** | 玩家生态 | 公会、摆摊、抽成、PvP、有人退坑 | 村庄有了「社会」 |
| **M5** | 真相 | 怀疑、试探、村长的原罪 | 最有分量，必须最后 |

M0→M2 是「村庄活起来了」；M3→M4 是「村庄有经济和社会」；M5 是「村庄有了代价」。

### 建筑是网，不是等级条（推翻旧的 tier 直线）

> ⚠️ **整张图是【推导】，不是开发者原话。** 开发者原话只列了四栋：
> 「武器店，服装店，又或者一些试炼塔，作用是让玩家快速升级，还有防护罩，
> 作用是保护村庄不被外面攻击等等」
>
> **「等等」里的建筑没有被指定，不要替他猜。** 见 `functional-buildings.md`。

```
副本 ──产材料──▶ 铁匠铺 ──▶ 武器店
  │                            │
  │                            ▼
  │需要强玩家              玩家变强
  ▼                            │
试炼塔（让玩家快速升级）──────────┘
              ▲
              │代价：越强越盖不动
              │
            防护罩（保护村庄不被外面攻击）
```

> ❌ **这里曾经画过一个「付费装备」节点——那是我编的，开发者从没提过。**
> 已被 `functional-buildings.md` 的作者抓出并移除。记在这里是为了防止它再被画回来。

**每栋建筑都在喂另一栋，也都在偷另一栋的资源。**

**试炼塔是村长给自己挖的坑**：玩家变强 → 盖房子失去吸引力 → 村庄盖不动了。
玩家每一步成长都在消耗村长的另一项资源。

### 三层经济，别混成一层

- **玩家 ↔ 玩家**：摆摊，村长抽成。风险是私下交易让抽成形同虚设
- **玩家 ↔ 村长**：武器店服装店，村长垄断。**唯一的印钞机**
- **村长 ↔ 世界**：副本材料。村长出命、人和时间

## 死亡：停一天才能上线

> **【开发者原话】**「死亡可以让这个玩家，过一天才能上线」——**就这一句。**

**【以下是我的推导，不是开发者说的】**
他不是永久删除，是停机一天。但如果他不知道这是真的，
**停机会被他体验成「删号」**——他会去看客服，会去论坛发帖问「怎么注销」，会来找 GM，
而村长一句也不能解释。

⚠️ **这句推导现在有一个具体的漏洞**：`death-and-revival.md` F7 已量出——
按「村庄日」读法，他平均只损失 `PlayHours/2`，**最坏情况损失 0**
（深夜倒下、晚上照常上线）。也就是说**按那个读法，他大半时候根本没「过掉一天」**，
上面那段推导有一半概率不成立。这条推导的成立与否，取决于下面那个未决问题。

**🔴 未决：「过一天」是村庄日还是地球日？** 详见 `death-and-revival.md` Q1。
两种读法各自的公式与边界都写全了，**但没有决定**——因为开发者没说。

## 玩家间交易的彩蛋（M4）

有人坏 → 交易不好的东西 → 别人发现 → 损失 → 吵架 → PvP →
上线就追着砍 → 被砍的只能跑野外升级 → 变强了回来报仇。

**这是因果链，不是剧本。** 它需要物品、交易、谎报品质、PvP、野外地图——
所以属于 M4，不是 M0。

## 已知风险

- **前三个原型都不能作为设计判据。** 它们是空壳。
- **「独一无二」不等于「随机乱 roll」。** 保底机制是必需品（三项之和 ≥ 60）。
- **杂谈只是面板**，但它是自主行为的**唯一读数器**——写得干，自主性就看不见了。
- **作息是双刃剑。** 村庄空着很有味道，但也可能让玩家以为卡了。
  已缓解：开局三个人钉在上班时间，让村庄有白天。
- **M0 已验证的行为**：`工地上0人 速度0.0000 进度冻结9小时` 是真的，
  不是描述。下次改动不要把它改回「不在线也照盖」。
