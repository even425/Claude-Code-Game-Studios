## 1. 大事件：第三个实例（基线 §11.5 待定）—— **已落地：D-096 盗匪来袭**

⇒ 新增实例**不要求重写核心世界循环**（基线 §11.1 的硬要求）⇒ 加一个模板即可。

## 2. 建筑：七栋候选（基线 §12.1 开发者原话）

### 2.1 口径提醒（免得白做）

- 基线 §12.1 有一句硬话：**「新增建筑必须由开发者提出，不得由实现者补充」** ⇒
  下面**七栋全部来自基线**，不是我加的。
- D-066 已裁决**七栋暂不做**（人口 / 采集点 / 装备三个大概念挡在门外）⇒
  **武器店 / 服装店** 属于「装备」那一族 ⇒ 若要做，等于**打开 D-066 的暂不做裁决** ⇒ 需要你明确。
- §12.3 同样有一句硬话：**「不能仅凭建筑名称自行指定功能」** ⇒
  每栋的功能**必须你定**（哪怕只是「它让村庄看起来更阔」也行，但要写下来）。

### 2.3 我的建议（供你参考，不是决定）

1. **先做防护罩**：它是基线里**唯一已经带明确规则**的（「摆摊受它约束」⇒ 落地即可测），
   而且它直接接上兽潮（D-085 刚证明「防御设施能守村」这条路走得通）。
2. **井 / 铁匠铺**走「层级附带建筑」这条最省事：现成的 5 级阶梯已经有这两个名字
   ⇒ 不用新造建造流程，只需在升级到那一级时把建筑放出来（并让玩家能看见）。
3. **武器店 / 服装店**先别碰（要开装备系统 ⇒ 一整轮）。

## 3. 拍板后我怎么落地（每一件的标准做法）

1. 在 `07` 落一条 `D-0xx`（拍板内容 + 数值 + 与旧决策的关系）。
2. 领域层先写规则（可离线单测）⇒ 接线到表现层 ⇒ 补守卫。
3. 数值**先算出来再写进代码**（例：防护罩的范围/削减 ⇒ 跑一次标定看它对兽潮与经济的影响）。
4. 真机自检（新增 `--xxx` 开关）⇒ 进 `run-selfchecks.py`。
5. 标定重跑 + 文档同步（`07` / `38` / 参数台账 / 进度总览）。
