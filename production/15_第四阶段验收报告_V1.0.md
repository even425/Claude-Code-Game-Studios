## 6. 兼容性 / 存档风险

| 项 | 结论 |
|---|---|
| 存档版本 | 0.3 → **0.4**；0.3 及更早**整份拒绝**，不写迁移器（沿用 I11 与项目惯例）。未测试「0.4 档被旧版本读取」（项目不支持降级） |
| 原子性 | 存档写入走 `SavePort` 临时文件 + `File.Move`；读档先 `SaveValidator` 全量校验，任一失败整份拒绝，不做部分恢复 |
| 幂等键空间 | `AppliedPurchaseKeys` 与 `AppliedTradeKeys` **分开**；后者留给尚未接线的英雄↔英雄交易，当前恒为空 |
| 价格表变更 | 读档恢复摊位单价，**不**按 `PriceBook` 重验；价格表变化不会让旧档整份失败 |
| 每日购物闸门 | `DailyShoppingLastRunDay` 比设计清单多存一项：不存它，读档后同一天会对未成交者再试一次 |
